# Generic agent bundle

This bundle provides provider-neutral role templates, research and verification skills, and command launchers. Installation-specific settings belong only in `assets/config/overlay.json`, created from `assets/config/overlay.example.json`.

This repository is the sole authored source for the generic bundle. Copies in project-specific ignored directories, temporary research labs, and installed OpenCode configuration directories are generated outputs or overlays, never upstream sources.

Model mappings are mandatory operator inputs. Templates contain `modelKey` references, not provider defaults. The example uses conspicuous `REQUIRED_PROVIDER/REQUIRED_MODEL` placeholders. The example recommends `experimental.subagent_depth: 3` (the OpenCode 2 serialized key), enabling the four-level chain: primary agent → lead → specialist/implementer → reviewer. Lower values remain operator choices for shallower chains; installers never mutate live configuration to enable any depth.

## Export and validation

```sh
node tools/bundle-assets.mjs export /absolute/isolated/destination /path/to/operator-overlay.json
node tools/bundle-assets.mjs validate /absolute/isolated/destination
node tools/bundle-assets.mjs doctor /absolute/isolated/destination
```

`export` stages output before replacing the destination and writes `.generic-bundle-manifest.json` containing deterministic asset hashes. Re-running it is idempotent. `validate` and `doctor` use stable diagnostics:

- `BUNDLE_MANIFEST_MISSING`, `BUNDLE_ASSET_MISSING`, `BUNDLE_ASSET_STALE`
- `BUNDLE_COMMAND_SKILL_MISSING`, `BUNDLE_PRODUCT_LEAKAGE`
- `BUNDLE_OVERLAY_MISSING`, `BUNDLE_HOST_API_UNSUPPORTED`, `BUNDLE_NESTED_DEPTH_INVALID`, `BUNDLE_PLUGIN_DUPLICATE`
- `BUNDLE_NESTED_DEPTH_UNAVAILABLE`, `BUNDLE_DEFAULT_AGENT_INVALID`, `BUNDLE_AGENT_UNKNOWN`, `BUNDLE_MODEL_ROUTE_REQUIRED`, `BUNDLE_PERMISSIONS_REQUIRED`

The destination must be isolated from the source repository. No command modifies global configuration.

OpenSpec skills and `opsx-*` commands are externally generated. They are deliberately absent and must be regenerated by their own generator; doctor does not classify them as authored bundle assets. Stale lifecycle artifacts are excluded. The legacy-v4 importer remains available only for an explicit non-empty import; the 149 empty project states observed during consolidation require no import.
